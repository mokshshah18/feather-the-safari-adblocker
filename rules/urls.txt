# URL rules: one regex per line, optional options after whitespace.
#
#   <regex> [load-type=first-party|third-party] [resource-type=script,image,...]
#           [if-domain=a.com,b.com] [unless-domain=...] [case-sensitive]
#
# Prefix a line with @@ to make it an exception (ignore-previous-rules).
#
# Regex rules: WebKit's content-blocker engine accepts only  . * + ? [ ] [^ ]
# ( ) ^ $  and \. escapes. No alternation (a|b), no {n,m}, no \d \w \s.
# Matching is case-insensitive unless case-sensitive is given.
# Use ^[a-z]+:// to anchor at the scheme and ([^/:]+\.)? for "any subdomain".

# ---- Google (first-party on google.*, so no load-type restriction)
^[a-z]+://adservice\.google\.[a-z.]+[/:]
^[a-z]+://([^/:]+\.)?google\.[a-z.]+/pagead/
^[a-z]+://www\.google\.[a-z.]+/ads/
^[a-z]+://www\.googletagmanager\.com/gtag/js

# ---- YouTube and YouTube Music ad and tracking endpoints

^[a-z]+://([^/:]+\.)?youtube\.com/api/stats/qoe

^[a-z]+://([^/:]+\.)?youtube\.com/csi_204
